# Contributing

Timeline is a personal project shared in the open. Bug reports and ideas are welcome as issues. For anything beyond a small fix, open an issue to discuss it before sending a pull request, since changes need to fit how the project is run and maintained.

Development setup, conventions, and the test commands live in [AGENTS.md](AGENTS.md). Every pull request needs `./test.sh` to pass and a changeset (see [docs/releases.md](docs/releases.md)).

Timeline handles very personal data. Never include real personal data in issues, pull requests, screenshots, tests, or fixtures; use synthetic examples such as Alice, Bob, and `example.com`.
