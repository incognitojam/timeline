A person's memory note now shows the contact it is linked to, or "Not linked to a contact", and you can choose a different contact or remove the link from the note's page. The page says when the contact is hidden, and asks before it saves a change. Restoring an earlier version of a note keeps its current contact. On the Memory page, people's notes that are not linked to a contact are marked "Not linked".
