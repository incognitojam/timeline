The Memory page lists projects as rows you open, each with its own page (`/memory/project/<key>`) holding its notes and its account-memory setting. A project's note leads back through a Memory › project breadcrumb, and deleting it returns to the project. Going back to Memory or a project, by Back or by a link, returns to where you had scrolled, and a note opened from the list shows its title, tab title and content at once while it loads.
