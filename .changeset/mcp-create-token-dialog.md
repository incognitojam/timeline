Creating an MCP token now opens a dialog: a label, the **Read-only** and **Tailnet only** options with what each is for, and then the new token with the steps to connect it, the URL and the `Bearer` header value ready to copy. A tailnet-only token gets the steps for a client on the tailnet or the Mac instead of claude.ai's. The page keeps a folded **Connect a client** entry with the same steps for later, and closing the dialog clears the token from the page.
