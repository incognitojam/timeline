Agents can read, update and delete a memory note about a hidden contact when they ask for it by name, and `get_contact_info` lists it. Such notes are still left out of the memory index an agent reads first, which now says how many it left out. The Memory page, the Claude import preview and the contact delete dialog no longer say that these notes are kept from agents. The delete dialog's warning that deleting would let agents read a hidden contact's notes is gone, and an import is no longer refused because a contact was hidden or shown after the preview.
