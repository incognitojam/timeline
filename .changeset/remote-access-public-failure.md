When **Make Public on the Internet** fails, the Remote Access menu now says why instead of silently staying tailnet only. If the device lacks the `funnel` node attribute, it says Funnel is not allowed for this device, tells you to allow it in your tailnet's access controls, and offers **Enable Funnel in Tailscale…** when Tailscale provides a link. The menu's copy item is now **Copy URL** in both modes.
