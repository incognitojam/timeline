When **Make Public on the Internet** fails, the Remote Access menu now says why instead of silently staying tailnet only. If Funnel is not enabled for the device, it says so, tells you to enable it in the Tailscale admin console, and offers **Enable Funnel in Tailscale…** when Tailscale provides a link. The menu's copy item is now **Copy URL** in both modes.
