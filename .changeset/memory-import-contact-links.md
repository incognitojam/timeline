Import from Claude now previews memory in plain words: each place the notes go, by project title, with counts such as "9 people" or "3 topics" that open to the note titles. Every person note shows which contact it will link to and why, or why it will not, and you can pick a different contact or choose not to link before importing. A note matched to a hidden contact says so, since linking it there keeps it from agents; hidden contacts appear in the contact search once you tick "Show hidden contacts when choosing".
